## 🆕 مستجدات الإصدار 2.9.5

### 🔒 أمان وصلاحيات

| الميزة | التفاصيل |
|--------|---------|
| **منح الموظف صلاحية تعديل سعر السلة** | المدير يستطيع منح أو إلغاء صلاحية تعديل أسعار المنتجات في السلة للموظف، من الإعدادات أو من زر الاختصار 🔒/🔓 في السلة مباشرة. يتطلب كلمة مرور المدير في كلتا الحالتين. |
| **تسجيل خروج تلقائي عند إعادة التشغيل** | عند إغلاق التطبيق وإعادة فتحه (أندرويد، حاسوب، ويب) يُطلب تسجيل الدخول من جديد تلقائياً — لا يبقى أي حساب مسجلاً بعد الإغلاق. |
| **حوار تأكيد الخروج على أندرويد** | ضغطة زر الرجوع من نقطة البيع أو من شاشة الدخول تعرض حوار اختيار: **إنهاء التطبيق** (مع تسجيل خروج) أو **تراجع**. لا يخرج التطبيق مباشرة. |

### 🔧 إصلاحات جوهرية (2.9.4)

| # | المشكلة | الإصلاح |
|---|---------|---------|
| 1 | **ماسح الباركود يحتاج ضغط زر يدوياً** | المسح الآن **تلقائي ومستمر** — وجّه الكاميرا نحو الرمز وسيُكتشف فوراً دون أي ضغط. |
| 2 | **جودة صورة الفاتورة عند الطباعة منخفضة** | رفع دقة التصيير من `scale:3` إلى `scale:4` مع `windowWidth:320` و`imageTimeout:5000`. |
| 3 | **الروابط الخارجية قد تُفتح داخل التطبيق** | تقليص `allowNavigation` من `*` إلى النطاقات المعتمدة فقط (OpenFoodFacts, allorigins, go-upc). |
| 4 | **شاشة الخطأ لا تتيح العودة** | `ErrorBoundary` يعرض الآن زر "← رجوع" لإلغاء الخطأ وزر "🔄 إنعاش" للإعادة الكاملة. |

### ✨ مزايا جديدة (2.9.4)

| الميزة | التفاصيل |
|--------|---------|
| **Live Scanner — مسح تلقائي مستمر** | الكاميرا تعمل مباشرة عند فتح نافذة المسح، وتُحلَّل 15 إطار/ثانية. عند اكتشاف الرمز: اهتزاز + وميض أخضر + تنفيذ فوري. لا يوجد زر تصوير. |
| **Overlay احترافي للماسح** | نافذة مسح شفافة وسط الشاشة مع خلفية داكنة، زوايا L زرقاء، وخط ليزر متحرك. |
| **زر كشاف الضوء (Torch)** | زر لتشغيل وإطفاء الفلاش مباشرة من شاشة المسح. |
| **أيقونات التطبيق الرسمية الجديدة** | تحديث شامل لـ `icon.png`، `icon.ico`، `icon.icns` بالأيقونة الرسمية الجديدة. |
| **سكريبت بناء آلي** | `build-apk.sh` يبني APK خطوة بخطوة مع 9 مراحل وتقرير ملوّن. |

## 📋 نظرة عامة

**متجري** هو نظام نقاط بيع (POS) مفتوح المصدر يعمل على **GNU/Linux** و **Android** — بدون اشتراك، بدون سحابة، بياناتك ملكك.

---

## ✨ المميزات الكاملة

| القسم | الوصف |
|-------|-------|
| 🛒 **نقطة البيع** | مسح باركود، سلة مبيعات مع زر نقص سريع، خصومات، طرق دفع، طباعة فاتورة + QR تسلسلي. |
| 📦 **المخزون** | بحث محلي ثم خارجي مع retry، إضافة مورد سريع، تصوير المنتج، قائمة فئات ذكية. |
| 👥 **الزبائن** | نقاط الولاء، سجل المشتريات، القسائم. |
| 🚚 **الموردون** | إدارة الموردين وربطهم بالمنتجات، إضافة سريعة من قسم المخزون. |
| 💳 **الديون** | تتبع ديون الزبائن، تعديل الديون، دفعات جزئية، تنبيهات التأخر. |
| ⭐ **الزكاة** | حاسبة زكاة المال حسب المذاهب الأربعة مع ترتيب صحيح لحقول الثروة. |
| 📊 **لوحة التحكم** | إحصائيات المبيعات، رسوم بيانية، تقارير، تصدير نسخة احتياطية شامل. |
| 🔍 **البحث الشامل** | مسح QR الفاتورة، إعادة طباعة، نظام مرتجعات شامل مع حساب المبلغ المسترد. |
| ⚙️ **الإعدادات** | موظفون، صلاحيات، طابعة حرارية، لغة، نسخ احتياطي يعمل على Android والحاسوب. |

**اللغات:** العربية 🇲🇦 · English · Français

## 🛠️ البناء من المصدر

### الطريقة الآلية (موصى بها):
```bash
chmod +x build-apk.sh
./build-apk.sh
```

### الطريقة اليدوية:
```bash
npm install
npx cap add android
npm run patch-android
node scripts/generate-android-icons.js
npm run build:web
npx cap sync android
cd android && ./gradlew assembleDebug
```
