## 🆕 مستجدات الإصدار 2.9.2

### 🔧 إصلاحات جوهرية

| # | المشكلة | الإصلاح |
|---|---------|---------|
| 1 | **نافذة الكاميرا/الصورة/الإدخال اليدوي شفافة** | خلفية سوداء صلبة `#000000` بدلاً من `bg-black/92` مع `z-index` أعلى لمنع تداخل المحتوى. |
| 2 | **رابط مشروع GitHub يفتح داخل التطبيق** | إضافة `import { openExternalLink }` المفقود في `Settings.tsx` — كانت الدالة مستخدَمة بدون استيراد. |
| 3 | **الآلة الحاسبة تكتب الرقم مرتين على الهاتف** | استبدال `onClick` + `onTouchStart` بـ `onPointerDown` مع `e.preventDefault()` للقضاء على الحدث المزدوج عند اللمس. |
| 4 | **حفظ الصورة لا يعمل على Android 10+** | الانتقال من `Directory.ExternalStorage` (يحتاج إذن مقيّد) إلى `Directory.Cache` + `Share.share` الذي يعرض واجهة الحفظ الأصلية للنظام. |
| 5 | **QR الفاتورة يحمل بيانات زائدة** | QR يحمل الآن الرقم التسلسلي للفاتورة فقط (`MTJR-XXXXXX`) — لا JSON، لا بيانات إضافية، مما يجعله أخف وأسرع في المسح. |
| 6 | **الفاتورة تفتح داخل التطبيق بلا طريقة للرجوع** | مشاركة الفاتورة كـ PNG عبر `Share.share` بدلاً من HTML — Android يفتحها في تطبيق الصور أو تطبيقات الطباعة الخارجية. |
| 7 | **النسخ الاحتياطية لا تعمل على Android** | `handleExportData` يستخدم الآن `Share.share` على Android (يفتح Drive / مدير الملفات) بينما يظل التنزيل المباشر على الحاسوب. |

### ✨ مزايا جديدة

| الميزة | التفاصيل |
|--------|---------|
| **إضافة مورد سريع من داخل المخزون** | زر "مورد جديد" بجانب حقل المورد في نافذة إضافة المنتج — يُدخل الاسم ونوع السلعة والهاتف فوراً دون مغادرة الصفحة. |
| **تصوير المنتج مباشرة من نافذة الإضافة** | زر كاميرا مدمج على صورة المنتج — يفتح الكاميرا الأصلية على Android ويضغط الصورة تلقائياً. |
| **مسح أو تصوير المنتج عند عدم وجوده أونلاين** | عند ظهور "المنتج غير مسجل عالمياً"، تظهر خيارات سريعة لتصوير المنتج ومسح باركوده وحفظهما محلياً. |
| **تسمية ملفات الفاتورة بالرقم التسلسلي** | اسم ملف الفاتورة المحفوظة يحمل نفس رقم الفاتورة: `فاتورة_MTJR-XXXXXX.png` لسهولة البحث في التخزين. |
| **رقم الفاتورة مرئي تحت QR** | الرقم التسلسلي `MTJR-XXXXXX` يظهر بخط `monospace` واضح أسفل كود QR في المعاينة وعند إعادة الطباعة. |
| **توجيه Share sheet للتطبيقات الصحيحة** | عنوان Share sheet يُوجّه المستخدم نحو تطبيقات الطباعة والمعرض والمستندات بدلاً من عرض كل التطبيقات. |
| **سكريبت بناء آلي** | إضافة `build-apk.sh` لبناء APK خطوة بخطوة مع التحقق من الأخطاء وتقرير مفصل بالألوان. |

## 📋 نظرة عامة

**متجري** هو نظام نقاط بيع (POS) مفتوح المصدر يعمل على **GNU/Linux** و **Android** — بدون اشتراك، بدون سحابة، بياناتك ملكك.

## ✨ المميزات الكاملة

| القسم | الوصف |
|-------|-------|
| 🛒 **نقطة البيع** | مسح باركود، سلة مبيعات، خصومات، طرق دفع متعددة، طباعة فاتورة + QR تسلسلي. |
| 📦 **المخزون** | إضافة/تعديل منتجات، جلب معلومات تلقائي عبر الباركود، تصوير المنتج، إضافة مورد سريع. |
| 👥 **الزبائن** | نقاط الولاء، سجل المشتريات، القسائم. |
| 🚚 **الموردون** | إدارة الموردين وربطهم بالمنتجات، إضافة سريعة من قسم المخزون. |
| 💳 **الديون** | تتبع ديون الزبائن، دفعات جزئية، تنبيهات التأخر. |
| ⭐ **الزكاة** | حاسبة زكاة المال حسب المذاهب الأربعة. |
| 📊 **لوحة التحكم** | إحصائيات المبيعات، رسوم بيانية، تقارير. |
| 🔍 **البحث الشامل** | البحث في المبيعات، مسح QR الفاتورة، إعادة طباعة، معالجة المرتجعات. |
| ⚙️ **الإعدادات** | موظفون، صلاحيات، طابعة حرارية، لغة، نسخ احتياطي يعمل على Android والحاسوب. |

## 🛠️ البناء من المصدر

### الطريقة اليدوية:
```bash
npm install
npx cap add android
npm run patch-android
node scripts/generate-android-icons.js
npm run build:web
npx cap sync android
cd android && ./gradlew assembleDebug
```

### الطريقة الآلية (موصى بها):
```bash
chmod +x build-apk.sh
./build-apk.sh
```

السكريبت الآلي يقوم ببناء التطبيق خطوة بخطوة مع:
- التحقق من نجاح كل أمر قبل الانتقال للتالي
- عرض تقرير مفصل بالألوان
- إيقاف العمل فور حدوث أي خطأ مع توضيح سببه
