## 🆕 مستجدات الإصدار 2.9.3

### 🔧 إصلاحات جوهرية

| # | المشكلة | الإصلاح |
|---|---------|---------|
| 1 | **زر التصدير في لوحة التحكم لا يعمل على Android** | يعمل الآن عبر `Share.share` على Android وتنزيل مباشر على الحاسوب، ويتضمن بيانات الديون. |
| 2 | **الديون لا تُستعاد عند رفع النسخة الاحتياطية** | كلا زرّي التصدير (لوحة التحكم + الإعدادات) يتضمنان حقل `debts` كاملاً. |
| 3 | **التطبيق لا يقترح نفسه لفتح ملفات النسخ الاحتياطية** | إضافة `intent-filter` لـ `application/json` في سكريبت بناء AndroidManifest. |
| 4 | **البحث لا يتحقق من القاعدة المحلية أولاً** | البحث يتحقق من المخزون المحلي قبل الاتصال بالإنترنت، مع retry ×2 وtimeout لكل مصدر. |
| 5 | **الدين لا يظهر في معاينة الفاتورة** | تنبيه أحمر واضح في شاشة معاينة الفاتورة عند اختيار طريقة الدفع "دين". |
| 6 | **لا يمكن تعديل الدين بعد إنشائه** | زر تعديل لكل دين + نافذة كاملة للمبلغ والأجل والهاتف والملاحظات. |
| 7 | **ترتيب حقول الزكاة مقلوب** | "ديون لي ✚ تُضاف" يسبق الآن "ديون علي ✖ تُطرح" مع ألوان مميزة لكل حقل. |
| 8 | **قائمة الفئات تحجب لوحة المفاتيح على الهاتف** | استُبدل `<datalist>` بقائمة منسدلة تفتح فقط عند النقر على السهم — لا تداخل مع الكتابة. |
| 9 | **لا يوجد زر نقص الكمية في سلة المنتجات** | زر `−` أحمر يظهر فوق بطاقة المنتج عند إضافته للسلة. |
| 10 | **المرتجعات لا تُسجَّل ولا تمنع التكرار** | نظام مرتجعات شامل: تتبع الكميات المرتجعة سابقاً، دمج المرتجعات الجزئية، منع إرجاع المنتج مرتين. |

### ✨ مزايا جديدة

| الميزة | التفاصيل |
|--------|---------|
| **المبلغ المسترد في المرتجعات** | يظهر المبلغ المسترد لكل صنف لحظياً عند التحديد والإجمالي قبل التأكيد، ويُحفظ في بيانات الفاتورة. |
| **تفاصيل المرتجع في الفاتورة** | قائمة كاملة بالأصناف المرتجعة وكمياتها وأسعارها والمبلغ الإجمالي المسترد في تفاصيل كل فاتورة. |
| **رقم الإصدار في الواجهة** | `v2.9.3-beta` يظهر في تذييل الإعدادات، القائمة الجانبية، والقائمة المتنقلة. |
| **Share sheet للنسخ الاحتياطية** | تصدير النسخة الاحتياطية من لوحة التحكم يعمل على Android عبر Share sheet. |
| **سكريبت بناء آلي** | `build-apk.sh` يبني APK خطوة بخطوة مع التحقق من الأخطاء وتقرير ملوّن. |

## 📋 نظرة عامة

**متجري** هو نظام نقاط بيع (POS) مفتوح المصدر يعمل على **GNU/Linux** و **Android** — بدون اشتراك، بدون سحابة، بياناتك ملكك.

---

## ✨ المميزات الكاملة

| القسم | الوصف |
|-------|-------|
| 🛒 **نقطة البيع** | مسح باركود، سلة مبيعات مع زر نقص سريع، خصومات، طرق دفع، طباعة فاتورة + QR تسلسلي. |
| 📦 **المخزون** | بحث محلي ثم خارجي مع retry، إضافة مورد سريع، تصوير المنتج، قائمة فئات ذكية. |
| 👥 **الزبائن** | نقاط الولاء، سجل المشتريات، القسائم. |
| 🚚 **الموردون** | إدارة الموردين وربطهم بالمنتجات، إضافة سريعة من قسم المخزون. |
| 💳 **الديون** | تتبع ديون الزبائن، تعديل الديون، دفعات جزئية، تنبيهات التأخر. |
| ⭐ **الزكاة** | حاسبة زكاة المال حسب المذاهب الأربعة مع ترتيب صحيح لحقول الثروة. |
| 📊 **لوحة التحكم** | إحصائيات المبيعات، رسوم بيانية، تقارير، تصدير نسخة احتياطية شامل. |
| 🔍 **البحث الشامل** | مسح QR الفاتورة، إعادة طباعة، نظام مرتجعات شامل مع حساب المبلغ المسترد. |
| ⚙️ **الإعدادات** | موظفون، صلاحيات، طابعة حرارية، لغة، نسخ احتياطي يعمل على Android والحاسوب. |

**اللغات:** العربية 🇲🇦 · English · Français

## 🛠️ البناء من المصدر

### الطريقة اليدوية:
```bash
npm install
npx cap add android
npm run patch-android
node scripts/generate-android-icons.js
npm run build:web
npx cap sync android
cd android && ./gradlew assembleDebug
```

### الطريقة الآلية (موصى بها):
```bash
chmod +x build-apk.sh
./build-apk.sh
```

السكريبت الآلي يقوم ببناء التطبيق خطوة بخطوة مع:
- التحقق من نجاح كل أمر قبل الانتقال للتالي
- عرض تقرير مفصل بالألوان
- إيقاف العمل فور حدوث أي خطأ مع توضيح سببه
